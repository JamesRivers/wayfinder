# K3s stack workspace

This directory will hold the K3s-based observability stack implementation.

Planned areas:
- `cluster/` — K3s bootstrap, ingress, and persistence notes
- `observability/` — Grafana, Prometheus, Mimir, Loki, and Tempo deployment assets
- `awx/` — AWX operator and Alloy orchestration assets
- `storage/` — Garage S3 and object storage wiring
